## Comment utiliser un lab

<div class="grid cards mtc-steps" markdown>

-   **1 · Télécharge**

    Sur la page du lab, le `.zip` (EVE-NG) ou le `.unl` (PNETLab). Pour Packet Tracer, la fiche ou le `.pkt`.

-   **2 · Importe**

    **EVE-NG** : menu *Import*, choisis le `.zip`. **PNETLab** : importe le `.zip` ou le `.unl`. Les images restent celles de ton serveur.

-   **3 · Répare**

    Lis le ticket, cherche la preuve avec les commandes, corrige. La solution et le schéma sont dans le lab.

</div>
